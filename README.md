# courses-website
# - Nahda Academy
A complete e-learning platform built with HTML, CSS, JavaScript and Bootstrap 5.

## Pages
- **Home** - Slider, statistics, and dynamic courses preview
- **Courses** - Display all available courses
- **Pricing** - Subscription plans
- **Contact Us** - Contact form

## Technologies Used
- HTML5 / CSS / JavaScript
- Bootstrap 5
- Font Awesome Icons
- Responsive Design

## Features
- Fully responsive design for all devices
- Arabic RTL interface
- Interactive registration modal
- Academy statistics (5000+ students, 50+ courses)
- Professional dark modern design
- Sticky Navbar
